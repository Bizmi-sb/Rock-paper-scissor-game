# Rock-paper-scissor-game
Program of rock , paper , scissor game using python 
Rock, Paper, Scissors is a classic hand game that is played between two players. The game is simple: each player simultaneously throws one of three hand signals: Rock, Paper, or Scissors. The winning hand beats the losing hand as follows:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
Gameplay:
-------------
1. The user is prompted to enter their choice of Rock, Paper, or Scissors.
2. The computer generates a random choice of Rock, Paper, or Scissors.
3. The user's choice is compared to the computer's choice to determine the winner.
4. The result of the game is displayed to the user.
